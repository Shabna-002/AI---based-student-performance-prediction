# 30 Viva Questions and Answers

1. What is the project? An AI-enabled student database and performance prediction system.
2. Why ML? To learn patterns from academic data.
3. Why MySQL? For structured relational storage.
4. Why Flask? Lightweight Python web framework.
5. What is Random Forest? An ensemble of decision trees.
6. What is classification? Assigning data to predefined classes.
7. What are the classes? High, Average and Low.
8. What is a feature? An input variable used by a model.
9. What is training data? Data used to learn the model.
10. What is testing data? Unseen data used for evaluation.
11. Why stratified split? To preserve class proportions.
12. What is accuracy? Correct predictions divided by total predictions.
13. What is precision? Correct predicted positives divided by predicted positives.
14. What is recall? Correct predicted positives divided by actual positives.
15. What is F1? Harmonic mean of precision and recall.
16. Why compare algorithms? To select a suitable model.
17. What is overfitting? Poor generalization after memorizing training patterns.
18. How reduce overfitting? Validation, regularization and complexity control.
19. What is normalization? Reducing database redundancy.
20. What is a foreign key? A reference to another table's key.
21. Why store predictions? For auditing and monitoring.
22. What is preprocessing? Cleaning and preparing data.
23. Why attendance? It may correlate with engagement.
24. What is model serialization? Saving a trained model for later use.
25. What is joblib? A Python persistence utility.
26. What is a dashboard? A visual summary of system information.
27. Is prediction guaranteed? No, it is an estimate.
28. What privacy issues exist? Student data needs secure access and handling.
29. Future scope? Explainable AI, stronger models and ERP integration.
30. Main contribution? Combining DBMS functions with predictive analytics.
